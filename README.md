# BMI Calculator

A beginner-friendly Python program that calculates BMI and classifies it into health categories.

## Features

- Takes weight in kilograms
- Takes height in metres
- Calculates BMI
- Displays BMI rounded to 2 decimal places
- Classifies BMI as Underweight, Normal, Overweight, or Obese
- Handles invalid and negative inputs

## How to Run

Run the following command:

python bmi_calculator.py

## BMI Categories

- Below 18.5: Underweight
- 18.5 - 24.9: Normal
- 25 - 29.9: Overweight
- 30 and above: Obese# BMI
